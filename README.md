# JavaScript Loops and Functions – Practice Tasks

This repository contains a collection of JavaScript practice tasks focused on building a strong foundation in functions, arrow functions, loops, conditional statements, mathematical operations, and nested loops.

These tasks are part of my Job Ready Mentorship Program and are designed to improve my problem-solving and JavaScript programming skills through hands-on practice.

## Topics Covered

- JavaScript Functions
- Arrow Functions
- Conditional Statements
- Modulo Operator
- For Loops
- Nested Loops
- Mathematical Operations
- Number Manipulation
- Boolean Logic
- Problem Solving

## Tasks

### 1. Even or Odd
Checks whether a number is even or odd using the modulo operator.

### 2. Result Evaluator – Pass or Fail
Evaluates student marks and returns Pass or Fail. It also handles invalid marks.

### 3. Maximum Finder – Largest of Three Numbers
Finds the largest value among three numbers without using built-in Math helpers.

### 4. Accumulator – Sum from 1 to N
Calculates the total sum from 1 to N using a loop.

### 5. Multiplication Table Generator
Prints the multiplication table of a given number from 1 to 10.

### 6. Digit Counter – Number Length Finder
Counts the number of digits in a number using mathematical operations and a loop.

### 7. Number Reverser
Reverses the digits of a number using mathematical operations.

### 8. Factorial Engine
Calculates the factorial of a number using a loop.

### 9. Prime Validator
Checks whether a given number is prime using a loop.

### 10. Pattern Builder – Star Triangle
Creates a star triangle pattern using nested loops.
